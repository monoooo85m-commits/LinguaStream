📖 Panduan Menggunakan LinguaStream

  1. Atur Groq API Key (Cukup 1x): Klik ⚙️ Pengaturan API di kanan atas, daftar gratis di console.groq.com, lalu tempel kunci (gsk_...) hingga status berubah menjadi API Siap ✓.
  2. Pilih File Video / Audio: Unggah video YouTube, TikTok, Instagram, atau rekaman suara dari perangkatmu. Sistem akan otomatis mengecilkan ukuran suaranya agar upload super cepat.
  3. Klik Mulai Transkripsi: Dalam hitungan detik, teks asli beserta terjemahan dan ringkasan materinya akan muncul otomatis.
  4. Belajar Interaktif: Klik pada kalimat mana saja di sebelah kanan untuk melompat langsung ke detik video tersebut.
