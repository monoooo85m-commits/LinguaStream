#Nama produk digital
Lingua Stream

#Latar belakang
Berawal dari belajar melewati media sosial dengan berbagai bahasa yang berbeda beda membuat rasa ingin tahu menjadi lebih besar.
Tetapi kita masih belum mengerti bahasa asing yang digunkan
akhirnya kita membuat website khusus yang dirancang untuk mengatasi permasalahan ini,kita memikirkan sebuah ide di mana sebuah audio video diubah kedalam sebuah teks 
agar lebih mudah mencatat,karena tidak semua orang memiliki gaya belajar yang sama 
dan dengan fitur tambahan berupa translate bahasa,jadi kita tidak akan kesulitan dalam memahami isi video yang menggunakan bahasa asing,
sehingga kita tidak perlu khawatir lagi mengenai bahasa yang digunakan.

#Teknologi yang digunkan
!Struktur dan antarmuka = HTML5 & CSS3 (CSS Grid, Flexbox, CSS Variables)
!Logika dan pemrosesan = JavaScript
!Pengelolahan audio lokal = Web audio API dan OfflineAudioContext
!Penyimpanan data = Web Storage API (localstorage)
!AI = Gemini Hydrogen dan Groq Cloud API
!Hosting dan Deployment = Github

#Panduan penggunaan
1. Langkah Menjalankan Lewat Tautan Situs Web Aktif (GitHub Pages)

- Buka Tautan Website:
Akses alamat GitHub Pages milikmu melalui browser (Chrome, Edge, atau Safari). Jika baru saja melakukan pembaruan kode, tekan Ctrl + Shift + R agar browser memuat versi terbaru.

- Hubungkan Kunci AI (Cukup 1 Kali):

- Klik tombol ⚙️ Pengaturan API di pojok kanan atas.

- Buka [console.groq.com/keys](https://console.groq.com/keys), masuk dengan akun Google/GitHub, lalu buat dan salin Groq API Key (gsk_...).

- Tempelkan ke kolom pengaturan di website dan klik Simpan Pengaturan hingga status di kanan atas berubah menjadi hijau (API Siap ✓).

- Unggah Media & Jalankan Transkripsi:

- Pada panel kiri, klik kotak Upload File lalu pilih file video (.mp4) atau audio (.mp3, .m4a, .wav) dari perangkatmu.

- Pilih bahasa asli video (atau biarkan Deteksi Otomatis) dan bahasa tujuan terjemahan (misal: Bahasa Indonesia).

- Klik tombol ⚡ Mulai Transkripsi & Terjemahkan.

- Gunakan Hasil Belajar:

Klik pada kotak kalimat mana saja di sebelah kanan untuk melompat langsung ke detik audio tersebut.
Buka tab 💡 Ringkasan Materi untuk membaca poin-poin rangkuman, atau klik 📥 Unduh Catatan (.md) untuk menyimpannya ke perangkat.
